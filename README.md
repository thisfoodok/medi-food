# 이거 먹어도 돼?

약 이름을 검색하면, 함께 먹으면 좋은 음식과 피해야 할 음식을 쉬운 말로 알려주는 웹앱입니다.

🔗 **바로 쓰기:** https://thisfoodok.github.io/medi-food/

## ⚠️ 중요 안내 (의료 면책)

이 앱이 제공하는 정보는 **일반적인 참고용**이며, 의학적 조언·진단·처방을 대체하지 않습니다.
복약, 식단, 치료와 관련된 모든 최종 판단은 반드시 **의사 또는 약사와 상담**하세요.
이 앱의 정보로 인해 발생한 결과에 대해 제작자는 책임지지 않습니다.

## 🔒 개인정보 처리방침

이 앱은 **어떤 개인정보도 수집·저장·전송하지 않습니다.**
별도의 서버가 없으며, 모든 검색과 처리는 **사용자 기기(브라우저) 안에서만** 이루어집니다.

## 📚 데이터 출처

약과 음식의 상호작용 정보는 아래 공개 자료를 참고하여 정리했습니다.

- 식품의약품안전처, 「약과 음식 상호작용을 피하는 복약안내서」

정보는 지속적으로 보완 중이며, 등록되지 않은 약은 "확인 불가"로 표시됩니다.
